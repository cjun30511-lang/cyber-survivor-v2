# 血焰修女 (Blood Nun) 资产说明文档

## 1. 交付文件清单
本目录包含以下 5 张图片，已全部验证为标准无损 PNG 编码格式：

*   `nun_portrait.png` (1024 × 1024)
    *   **用途**：主立绘资源，用于选人界面、大厅背景或结算界面。
    *   **格式**：无透明通道（RGB），默认带暗黑哥特仪式厅石柱背景。
*   `nun_portrait_transparent.png` (1024 × 1024)
    *   **用途**：UI 头像、对话框或界面悬浮立绘。
    *   **格式**：带透明通道（RGBA），已通过算法剔除暗色背景。
*   `nun_topdown_ingame.png` (1024 × 1024)
    *   **用途**：局内动作精灵主资源，俯视战斗视角。
    *   **格式**：无透明通道（RGB），默认带纯黑背景。
*   `nun_topdown_ingame_transparent.png` (1024 × 1024)
    *   **用途**：可以直接接入游戏的局内角色精灵。
    *   **格式**：带透明通道（RGBA），已剥离背景，保留完整的动作轮廓与武器边缘。
*   `nun_topdown_ingame_transparent_thumb.png` (128 × 128)
    *   **用途**：轻量级缩略精灵，适合低内存测试或小尺寸角色精灵。
    *   **格式**：带透明通道（RGBA），完全从最新版 `nun_topdown_ingame_transparent.png` 降采样导出，视觉内容保持绝对一致。

## 2. 视角与风格规格
*   **视角描述**：正统 2D 俯视（Top-down / Overhead）战斗视角，面向正前方。可直接看清头兜帽顶部、披肩的肩部结构以及斜握伸出的十字圣像杖。
*   **色调定位**：煤黑、炭灰、暗金为主体，边缘带有血焰灼橙色的环境反光，确保在暗色地表背景上的剪影清晰度。

## 3. 接入说明
*   **直接接入文件**：`nun_topdown_ingame_transparent.png`（高清版）或 `nun_topdown_ingame_transparent_thumb.png`（轻量版）。
*   在引擎内直接作为 `Sprite` 纹理加载，已剔除黑边，阴影直接与地表贴图融合。
